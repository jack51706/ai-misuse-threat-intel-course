# 全站查核與公開勘誤

> 2026-09-19 建立。這裡說明這次改了什麼、核對到哪裡，以及哪些事情仍未驗證。

## 1. 如何解讀每頁的查核狀態

| 頁首標記 | 代表什麼 | 不代表什麼 |
|---|---|---|
| 已核對指定來源項目 | 頁首展開區會列出核對日期、項目與範圍 | 不代表整份教材的所有事實、IOC 或防禦效果都驗證完成 |
| 結構已檢查・來源待逐項複核 | 已檢視本次導讀與章節結構，並檢查本機連結 | 不等於原文引述、歸因、圖表數字或外部連結全部重新查證 |
| 待審：新教材 | 尚未登錄該頁的編輯審核版本 | 自動增補或建置成功不等於人工核可 |
| 待審：內容已變更 | 本文與最近登錄的審核版本不同，舊日期不適用 | 不代表變更一定有錯；表示需要重新檢視修訂差異 |

**日期分開記**：來源發布日、教材加入日、結構檢查日、指定來源核對日不是同一件事。頁首的「來源逐項查證：尚未完成」會保留在未核對頁，不以今天的建置日期代替。

系統會比較教材版本；新增或變更內容後，不能直接沿用舊的來源核對標記。延伸研究導論的自動收錄表只負責列出教材，不為表內新研究背書。每份新研究另有自己的狀態。

## 4. 還有哪些待驗證事項

1. 歷史教材的全部外部來源、引文、圖表、ATT&CK 對應與 IOC 尚未逐項重新核對。不得將本次結構檢查當成全面事實認證。
2. 平台自述的歸因、完整提示序列與濫用母體通常未公開；本課無法獨立重現。
3. 本站沒有取得讀者的正式環境或日誌；偵測規則仍須補基線、誤報／漏報、權限與維運驗收。
4. 三套合成實作的情境有限。刻意保留的漏報不能因程式通過測試就忽略；也不可用小樣本結果評比產品。
5. 本次沒有對 IOC 連線、解析或互動式查詢；所有生物與武器內容維持治理與偵測範圍。

## 5. 後續更正怎麼提交

提出勘誤時，請附上**頁面與章節、待更正的句子、一手來源的頁碼或段落、建議改寫及其限制**。若沒有原始材料，可以先提出疑點，不需要猜補結論。

維護者應檢視差異，更新正文及該頁的核對範圍；只有實際讀到並核對的來源項目才填來源核對日期。新稿可保留「待審」公開供討論，但不得自動改成「已查證」。
