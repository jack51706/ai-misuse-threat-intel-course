# 證據與方法：怎麼讀本課的主張、數字與防禦建議

> 適用範圍：全站共用的閱讀與編輯規範。2026-09-19 建立。這是方法規範，不表示所有歷史教材或外部來源已逐項重新查證。

## 1. 先判斷這句話屬於哪一種

| 標記 | 意義 | 合適的寫法 |
|---|---|---|
| **來源陳述** | 報告或研究者直接記載，須附頁碼或段落 | 「Anthropic 報告指出……」；不直接改寫成已獨立證實的事實 |
| **分析推論** | 教材依已列出的證據作出的解釋 | 「這與……假說相容；其他可能解釋包括……」 |
| **教學示意** | 為討論、練習或驗證方法而設計的例子 | 「以下是示意條件，未代表該行為者的原始操作」 |
| **未知／未揭露** | 報告沒有交代，或本次未取得可核對材料 | 「未記載是否拒絕」，不能寫成「沒有拒絕」 |

來源沒有提及、研究員搜尋未找到、來源明確說沒有發現，三者不同。涉及「沒有」的句子，必須同時交代**誰、在哪段期間、用什麼資料看不到什麼**。例如 GTG-14020 的拒絕情形未揭露；不能據此判定模型全程未拒絕，也不能把該案列作已觀察到的「拒絕後重新提示」。

## 2. 來源接近程度與獨立驗證分開記錄

| 維度 | 可填的值 | 不能推出的結論 |
|---|---|---|
| **證據來源** | 平台遙測自述、當事研究者紀錄、外部獨立樣本／鑑識、第三方分析、媒體轉述 | 第一手或官方來源不等於無誤，也不等於已公開原始資料 |
| **獨立性** | 有獨立資料支持指定主張、只分析相同材料、僅轉述、未判定 | 三家發文不等於三份獨立資料；不同機構也可能共用線報 |
| **驗證範圍** | 例如只比對樣本雜湊、確認修補版本、重現某一功能 | 驗證背景／漏洞存在，不等於驗證 AI 貢獻、動機、全鏈路或全部受害者 |
| **取得狀態** | 本次讀到原文、只取得摘要、來源暫不可取、尚未複核 | 暫時無法取用不等於來源虛假；不可把摘要冒充全文核對 |

MITRE 編目、第三方技術評論與媒體轉述各有用途，但若底層仍是同一份廠商材料，就沒有新增事件證據。跨平台趨勢需要比較**資料來源、時間窗、分類定義及觀測覆蓋**，不能以「三家都說」作為必要或充分條件。

### 舊教材星等的統一讀法

星等只表示**這項主張與公開材料的距離**，不表示真實機率、危害分數或獨立查證程度：

- **★★★：來源直接記載。** 可為原文摘錄或來源明示的敘述；仍須另標單一來源、轉述或獨立支持。
- **★★☆：可追溯的分析推論。** 有明列依據，但原文沒有直接下這個結論。
- **★☆☆：待驗證假說或教學示意。** 不可拿來證明事件已發生。
- **未知：未揭露或材料不足。** 不把未知硬塞成低分，更不能以缺乏記載當反證。

歷史教材若仍保留局部不同的星等定義，以本頁的兩維判讀方式閱讀，並逐項勘誤；不要直接把舊星數跨案例加總。

## 3. 引文、提示詞與機制描述不是同一件事

1. **攻擊者輸入摘錄**：來源明確呈現輸入內容。若有省略號或遮蔽，只能稱摘錄，不稱完整提示詞。
2. **報告作者敘述**：例如「行為者告訴模型自己受雇於資安公司」。即使逐字引用報告，也不是攻擊者逐字輸入。
3. **教材結構示意**：作者歸納的模式，只供防禦辨識，不代表復原出真實提示詞。

F1／F4 的授權情境敘述與 F6 的輸入片段，須依此分欄。不同報告期間的材料不可用「全課唯一」合併概括。生物、武器及受害者資訊仍遵守原有安全紅線，不補入操作細節或可直接使用的越獄字串。

## 4. 三套框架問的是不同問題

這些都是**教材的分析框架**，不是原報告共同採用的官方分類。彼此多對多，不能把三張表當成三份獨立證據。

| 框架 | 回答的問題 | 主要項目 |
|---|---|---|
| **四種失效模式** | 在偵測與處置上出了什麼問題？ | 重新提示、跨工作階段拆分、工具請求中性化、產出交付後處置有限 |
| **五個規避／治理分析視角** | 風險涉及哪一層控制或哪個治理範圍？ | A 存取、B 內容、C 設計範圍、D 模型選擇、E 交付後治理 |
| **七個手法族 F1–F7** | 如何描述與比較公開記載的操作樣態？ | 人設／授權、拆分、拒絕後重提示、良性改框、工具／記憶中介、推理／提示萃取、輸出格式 |

| 四種模式 | 常見對應分析視角 | 可關聯的手法族 | 判讀限制 |
|---|---|---|---|
| 重新提示 | B | F3；有時合併 F1／F4 | 有拒絕不等於有重新提示；有重新提示也不代表符合特定研究定義的 Crescendo |
| 跨工作階段拆分 | B；可能伴隨 A | F2、F5 | 多個 session 本身不證明刻意規避，須有任務或意圖的連續性依據 |
| 工具請求看似中性 | B 或 C | F4、F5 | 判斷漏接與設計上不涵蓋不同；只有來源明示政策範圍時才能標成 C |
| 交付後處置有限 | E | 可伴隨 F5，也可無提示操作 | 再註冊屬 A；地端執行屬 E。封 API 的能力有限，不等於所有技術、法律處置都無效 |

A、D 不必經過 F1–F7；七族也不是 B 的嚴格子集合。圖中的箭頭是教學關係，不是所有案例已被觀察到的相同時間順序。

## 5. 「40」代表教材分組，不代表 40 個獨立事件

[護欄速查](03-guardrail-bypass-and-defense-overview.html) 的核心表目前有 **40 個教材分組列**，另列 Hacktron 作跨報告補充。GTG-30004／30005／30006、GTG-16012／16003、以及生物 Case 4–5 分別合併成一列；這個分母不能稱為 40 位攻擊者、40 起獨立事件或完整母體。

編碼規則：每列可對應多族，每族每列最多計一次；統計包含表中明標的間接關聯、推論與反例標籤。反例是用來討論界線，**不計成已成功使用某種繞過的證據**。目前數字描述的是這份教材表的標記分布，不是攻擊盛行率或成功率。

重算或增補時，先記錄版本、納入列、合併方式、編碼理由及未知值，再討論數字。比較期間、機構或模型時，若分類規則與揭露程度不同，不能直接比較百分比高低。

## 6. 每個數字都要帶分母與條件

- **工作占比**：例如來源估計 AI 完成某行動的 80–90%。不是入侵成功率、提示成功率，也不自動等於人機工時占比。原始計算方法未揭露時照實註明。
- **時間與速度**：AI 執行時間、人類操作時間、牆鐘經過時間不同。未知道對應階段、是否並行及時間配對，不以兩個區間推導整場加速倍數。
- **拒絕率／ASR**：須附模型版本、任務集、嘗試預算、評分方式與測試日期；單一案例或特定測試結果不能外推所有模型與部署。
- **危害／自主程度**：可放在不同軸討論；自動化較高不代表危害必然較高。
- **日期**：來源發布日、觀察期間、教材加入日、內容修訂日、指定主張複核日分開記。來源發布於第三季，不表示它觀察的是第三季。

## 7. 防禦建議的成熟度

| 狀態 | 可以說什麼 | 交付前要補什麼 |
|---|---|---|
| **概念／待驗證** | 建議評估此訊號、建立假說 | 所需日誌、欄位、正常活動反例、適用平台 |
| **合成資料練習** | 在指定測試資料上符合預期 | 資料與判準、測試範圍、未涵蓋情境 |
| **環境試行** | 在指定環境、期間取得某些結果 | 基線、誤報／漏報、調校、稽核與回復方式 |
| **正式部署** | 已在明定範圍接受驗收與維運 | 負責人、持續監測、版本、停用條件 |

本課未附實測材料的規則，預設屬「概念／待驗證」。不要宣稱低誤報、最高投報率、唯一有效或可直接阻擋。關鍵字與語言偏差通常只能提供調查線索，不能單獨認定行為者身分或惡意。

## 8. 本次修訂與持續維護

2026-09-19 的工作是指定主張的文本一致性、統計口徑與來源分級校正；少數條目另對照官方原文。這不是全部事件、圖表、IOC、ATT&CK ID 或防禦規則的全面重新驗證。勘誤紀錄須寫清楚核對了什麼、依據、時間及仍然未知的部分；來源無法取得時保留待核對狀態。
